安装与使用说明

IPA 直接安装

  1. 在 iPhone / iPad 的 Safari 打开软件详情。
  2. 确认系统与设备要求，点击“直接安装”，再按系统提示操作。
  3. 此入口需要可用签名或兼容的 AppSync 越狱环境；OTA 链接本身不会解除系统签名限制。
  4. 没有提示或无法安装时，选择“下载 IPA”，用 Filza、iFile 或兼容的 IPA 安装器打开。

使用 HTTPS 清单与系统 itms-services 入口。清单、下载链接可访问不等于每台设备都能成功安装。桌面电脑可以下载文件，但不能直接安装 iOS 应用。

更新前备份存档，保持原 Bundle ID。不要同时混装同一应用的 IPA 与 DEB 副本。

Cydia 软件源

https://chanlx86.github.io/repo/

在 Cydia → 软件源 → 编辑 → 添加中输入上面的地址，刷新后搜索软件。

添加到 CydiaSileoZebra

本源为传统 rootful 软件源；iOS 与架构范围以软件包及详情说明为准。所需第三方依赖需从其可信来源获取。补丁安装或卸载后，彻底退出目标 App 再打开。

旧的根地址仍提供兼容索引。新用户请使用 /repo/ 地址，已添加旧地址的用户无需重复添加两个源。

下载与校验

下载列表提供 SHA-256。Mac 使用 shasum -a 256 文件名，Windows PowerShell 使用 Get-FileHash 文件名 -Algorithm SHA256。回退前先备份数据，旧版未必能读取新版存档。
