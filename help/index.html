GETTING STARTED

先读说明，再安装。

不同的软件，可能有不同的系统、架构和越狱要求。

01 / 添加 Cydia 软件源

  1. 在已越狱设备的 Safari 打开本站，点击“添加到 Cydia”。
  2. 或者在 Cydia → 软件源 → 编辑 → 添加，输入 https://chanlx86.github.io/。
  3. 刷新后搜索需要的软件，确认依赖和版本，再安装。
  4. 插件类补丁安装后，彻底退出对应应用再打开；仅在安装提示要求时重新载入桌面。
添加到 Cydia

本源的 DEB 面向传统 rootful 环境，并非现代 rootless 越狱包。Package 内的系统依赖约束不代表所有对应系统都经过实测，仍以详情说明为准。

本源目前通过 GitHub Pages 的 HTTPS 提供，未发布独立的 GPG 签名。Cydia 可能提示来源未签名。若旧系统遇到 TLS 连接问题，先核对日期和系统证书环境；不要关闭全局证书校验。

02 / 下载与安装 IPA

IPA 下载不会自动完成安装。本页包主要采用本地 ad hoc／伪签名，适用于已有兼容安装环境的越狱设备，并非 App Store 或 Apple 正式分发包。

已配置 AppSync 与兼容安装器的设备，可用 Filza 等工具打开下载的 IPA；是否能成功安装还取决于包、系统与安装器版本。没有此环境时，需使用自己合法可用的签名方式。

IPA 容器安装和 DEB 系统目录安装可能使用不同数据位置。不要为同一个应用同时混装两种副本，也不要未经备份直接卸载旧版。

03 / 校验与回退

每个文件下方提供 SHA-256。Mac 可运行 shasum -a 256 文件名，Windows PowerShell 可运行 Get-FileHash 文件名 -Algorithm SHA256。它用于发现文件损坏，不等同于开发者身份认证。

保留旧包与存档。旧版程序未必能读取新版数据，不能只安装旧包就保证无损回退。历史文件可以在“版本归档”和软件详情页找到。
